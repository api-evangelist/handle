# Handle

> Handle (Handle Inc., handle.com) is a San Francisco software company, founded in 2018 by
> Patrick Hogan, Blake Robertson, Lucas Azevedo and Chris Woodard, that builds financial
> operations software for the construction industry: lien and notice management, automated
> lien-waiver exchange, full-service research and verification, automatic state-by-state
> compliance deadlines, job sheets, credit applications, collections, and construction-native
> online payments. Handle markets ERP integrations and operates a live API host at
> api.handle.com, and its own status page monitors components named "Main Portal API" and
> "Payment Portal API" — but Handle publishes no developer portal, no API reference, and no
> machine-readable specification of any kind. The only public route to the integration
> surface is a Contact Sales form.

This file was generated by API Evangelist from the public Handle surface on 2026-08-22.
It is a third-party profile, not a Handle publication. Handle serves no llms.txt of its own
(https://www.handle.com/llms.txt returns HTTP 404).

## Platform

- [The Handle Platform](https://www.handle.com/): lien rights, waivers, payments and credit operations in one system.
- [Lien & Notice Management](https://www.handle.com/payment-compliance/notice-management/): preliminary notices and lien filings across all 50 states.
- [Waiver Management](https://www.handle.com/payment-compliance/waiver-management/): conditional and unconditional lien-waiver exchange.
- [Full Service Verification](https://www.handle.com/payment-compliance/full-service-verification/): research and verification of project and party data.
- [Deadline Management](https://www.handle.com/payment-compliance/deadline-management/): automatic state-by-state compliance deadlines.
- [Job Sheet Optimization](https://www.handle.com/payment-compliance/job-sheet-optimization/): job information capture and cleanup.
- [Construction-Native Payments](https://www.handle.com/payment-processing/construction-native/): every payment linked to its waiver, lien and deadline.
- [Apply for Credit](https://www.handle.com/apply-for-credit/): digital credit application intake.

## APIs and specifications

- No OpenAPI, AsyncAPI, GraphQL SDL, Protobuf, WSDL, JSON Schema or Postman collection is published on any Handle host.
- No hosted MCP server and no A2A agent card were found. /.well-known/agent-card.json and /.well-known/agent.json return 404 on www.handle.com and api.handle.com.
- api.handle.com is live: the root returns HTTP 404 "Cannot GET /", and /api returns `{"message":"specify a valid api route like {/api/integrations/{integration_name}/{action}"}`. That route hint is the only public description of the surface.
- The status page monitors "Main Portal API" (since 2023-02-08) and "Payment Portal API", so APIs exist operationally; they are not publicly documented.
- [ERP Integrations](https://www.handle.com/erp-integrations/): "Handle integrates with any ERP", most customers live in 4-8 weeks. The page's only calls to action are Contact Sales and a link to the trust page.
